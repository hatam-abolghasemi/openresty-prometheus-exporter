# Code of conduct

This project is a place to build something useful together. Everyone taking
part (in issues, discussions, pull requests and reviews) is expected to help
keep it that way.

## Expected

- Be respectful and assume good intent. People here have different
  backgrounds, levels of experience and first languages.
- Critique ideas and code, not people. Explain the *why* behind a "no".
- Be patient with questions; everyone started somewhere.
- Credit other people's work.

## Not acceptable

- Harassment, insults, or derogatory comments about anyone's identity,
  background or ability.
- Sexualized language or imagery, unwelcome attention, or threats.
- Publishing someone's private information without their consent.
- Repeatedly derailing discussions or ignoring a maintainer's request to stop.

## Enforcement

Report problems privately to the maintainer,
[@hatam-abolghasemi](https://github.com/hatam-abolghasemi), via the email on
the GitHub profile. Reports are handled confidentially.

The maintainer may edit or remove comments, commits, issues and pull requests
that break this code, and may warn, temporarily block, or permanently ban
contributors, depending on how serious and repeated the behavior is.

This code applies in all project spaces, and in public spaces when someone is
representing the project.
